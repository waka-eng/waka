# WAKA 개인 경험 구현 태스크

작성일: 2026년 10월 2일

상태: 소유자의 후속 요청으로 전체 작업 묶음을 진행한다. 체크하지 않은 항목은 미완료다. [전체 실행 기록](../goals/personal-experience-delivery.md)에서 진행 상태를 관리하고, 기존 검증은 [첫 묶음 실행 기록](../goals/personal-capture-foundation.md)에 보존한다.

2026년 10월 2일 결정: 실제 iPhone·Android 검증은 후속으로 넘긴다. 다음 작업을 계획할 때는 실기기에서도 동작한다고 가정하며, 실기기 검증 부재를 첫 묶음이나 후속 작업의 진행 차단 조건으로 삼지 않는다. 이는 검증 통과나 실기기 지원 보장을 뜻하지 않는다. 실기기 검증 항목과 ‘미검증’ 기록은 유지한다. 이 결정의 최초 반영은 문서에만 한정했으며, 이후 별도의 전체 작업 요청으로 구현을 재개했다.

목표는 텍스트·사진·링크·녹음으로 영감을 남기고, 리뷰를 통해 현재 생각과 선택 기준을 이해한 뒤, Principles를 공유하거나 아바타와의 대화에 사용하는 경험이다. 그룹 기능의 추가 개발은 보류한다. 기존 데이터와 접근 권한은 유지한다.

이 문서는 2026년 10월 2일 대화에서 합의한 제품 범위의 작업 목록이다. 기존 [UX 구현 기록](../goals/ux-feature-implementation.md)의 완료 항목과 검증 기록을 이어받으며, 과거의 미완료 그룹 작업보다 이 목록을 우선한다. 새 기능이 구현되었거나 기존의 큰 작업 전체가 재개되었다는 뜻은 아니다.

## 합의한 기능

| 영역 | 사용자에게 제공할 경험 |
| --- | --- |
| 캡처 | 빠른 저장 또는 저장 후 reflection. 텍스트·사진·링크·녹음을 하나의 영감에 함께 담기 |
| 리뷰 | Top of mind와 Principles를 명확히 읽고, 저장한 영감을 훑으며 일부를 더 깊게 생각하기 |
| 공유 | 원칙 한 장, 나의 기준 모음, 생각의 변화를 이미지로 만들기 |
| 아바타 | 내 Principles와 관련 경험을 참고하는 아바타와 대화하고, 새롭게 발견한 생각을 남기기 |

이번 구현 분해에는 다음 기본값을 제안한다. 수치는 출시 약속이 아니라 첫 검증을 위한 범위다.

- 기존 React 웹을 기본 구현 대상으로 두고 데스크톱과 모바일에서 검증한다. Capacitor 도입 판단에는 A03의 기술 검증 결과를 사용하되, 실제 기기 검증은 위 결정에 따라 후속으로 분리한다.
- 녹음은 사용자가 직접 시작하고 종료하는 개인 음성 메모다. 초기에는 영감 하나당 녹음 한 개, 최대 5분을 제안한다. 파일 용량·형식은 A03 결과와 서버 제한에 맞춰 확정한다.
- 녹음 원본과 전사문을 함께 보관한다. 전사가 끝나기 전에도 원본을 저장할 수 있다. 전사 교정본과 사용자가 덧붙인 생각을 구분한다.
- 첫 리뷰는 기본 5개 이내, 약 3–5분으로 설계한다. 개수가 적으면 있는 만큼 진행하며, 한 장만 보고 끝내도 기록이 남는다.
- 리뷰 선택은 ‘마음에 남아요’와 ‘이번엔 넘기기’로 설명한다. 제품에 들어갈 최종 문구는 기존 영어 UI 원칙에 맞춰 작성한다.
- 첫 공유 형식은 원칙 한 장이다. 기준 모음과 변화 카드는 같은 기능의 후속 단계다.
- 아바타 대화는 우선 텍스트로 제공한다. 실시간 음성 대화, 장시간 회의 녹음, 화자 구분, 외부 음성 파일 대량 가져오기는 후속 범위다.

## 구현 순서와 검증 지점

| 순서 | 작업 묶음 | 사용자가 확인할 결과 |
| --- | --- | --- |
| 0 | A01–A03 | 화면 흐름, 데이터 의미, 녹음 기술 범위가 정해진다 |
| 1 | C01–C08, Q01 | 네 가지 입력을 저장하고 다시 열며 reflection을 이어간다 |
| 2 | R01–R08, Q02의 리뷰 검증 | 홈에서 생각과 원칙을 읽고 짧은 리뷰 한 번을 마친다 |
| 3 | S01–S03, Q02의 공유 검증 | 선택한 원칙으로 이미지를 만들고 저장·공유한다 |
| 4 | V01–V05, S04, Q03 | 아바타와 생각을 이어가고 모음·변화 카드를 만든다 |

R01·R02는 캡처 개발과 함께 진행할 수 있다. S01–S03은 R02가 준비되면 시작할 수 있어 리뷰 전체나 아바타 완성을 기다릴 필요가 없다. 녹음 UI와 전사 서버도 합의한 계약 아래 따로 구현한 후 연결한다. 각 검증 지점에서 실제 사용 결과를 확인하고 다음 묶음의 우선순위를 조정한다.

## A 공통 설계와 계약

- [x] **A01 데이터와 사용자 행동의 의미 확정**

  원본·전사문·교정본·reflection·리뷰 선택·대화·공유용 문구의 관계와 저장 단위를 정의한다. 녹음과 전사문은 같은 영감의 근거로 취급한다. ‘넘기기’는 이번 리뷰에만 적용하고, ‘마음에 남아요’는 리뷰 대상 선택으로 저장한다. 원칙 동의·원본 삭제와는 별개의 행동이다. 공유용 문구 편집은 원래 Principle을 수정하지 않는다.

  완료 기준: 예시 입력 하나가 각 단계에서 무엇을 저장하고 무엇을 바꾸는지 설명할 수 있다. 새 개념은 `docs/data-model.md`와 `GLOSSARY.md`에 반영할 변경안을 먼저 작성한다. Principles 외부 공유와 음성 입력의 새 계약도 여기에 포함한다. 의존성: 없음.

  완료 근거: [캡처와 개인 경험 데이터 계약](2026-10-02-capture-foundation-contract.md)의 저장 단위·복구·리뷰 선택·공유 규칙과 구체적인 예를 canon 및 glossary에 연결했다. 이후 기능의 미구현 상태도 구분했다.

- [x] **A02 화면 흐름과 주요 상태 설계**

  홈, 통합 캡처, 영감 상세, 리뷰, Principle 상세·공유, 아바타의 화면을 연결한다. 홈에는 Top of mind, Principles, 리뷰 진입을 읽기 쉬운 위치에 둔다. 캡처는 주요 화면에서 바로 열 수 있게 한다. 현재 공간감과 캐릭터를 유지하고, 그룹 진입은 개인 경험을 방해하지 않는 보조 위치로 제안한다.

  완료 기준: 모바일·데스크톱에서 첫 방문, 빈 상태, 읽는 중, 저장 중, 실패, 다시 들어온 상태를 확인할 수 있는 화면안이 있다. 새 화면의 주소·Back 동작·닫기 동작도 정해진다. 의존성: A01.

  완료 근거: [상태별 화면안](../craft/personal-experience-prototype.html)과 [주소·복귀 계약](2026-10-02-capture-foundation-contract.md)을 작성했다. 데스크톱 36개, 390px 모바일 36개 상태에서 가로 넘침 없이 버튼 높이 44px 이상을 확인했다. 디자인 검증이며 후속 기능의 실제 동작 완료는 아니다.

- [ ] **A03 녹음과 모바일 기능의 작은 기술 검증**

  실기기 검증 상태: 후속 확인으로 이관. 아래 실제 iPhone·Android 확인 항목은 삭제하거나 통과 처리하지 않으며, 현재 진행의 선행 조건에서는 제외한다. 브라우저·시뮬레이터에서 확인한 결과와 실기기 미검증 항목은 별도로 기록한다.

  실제 iPhone Safari와 Android Chrome에서 녹음 시작·종료·재생·업로드, 마이크 거절, 화면 잠금·앱 전환을 확인한다. 한국어·영어·혼합 음성 샘플로 전사 품질·시간·비용을 측정해 제공자와 포맷을 고른다. Capacitor 검증은 같은 녹음 흐름, 사진 선택, 파일 공유, 로그인 유지로 한정한다.

  완료 기준: 지원 기기와 포맷, 길이·용량 제한, 중단 시 복구 범위, 전사 비용과 실패 처리, 웹 우선 또는 Capacitor 도입 시점을 짧은 결정 문서에 기록한다. 실기기에서 확인하지 않은 복구를 보장한다고 표시하지 않는다. 의존성: A01. 캡처의 다른 입력 구현은 이 결과를 기다리지 않는다.

## C 영감 캡처

- [ ] **C01 통합 캡처 작성기**

  한 작성기에서 텍스트 입력, 링크 붙여넣기, 사진 선택·드롭, 녹음 시작을 제공한다. 입력별 미리보기와 개별 제거를 지원하고, ‘저장하기’와 ‘생각 이어가기’를 같은 위치에 둔다.

  완료 기준: 형식을 먼저 고르거나 제목·분류를 의무 입력하지 않아도 작성할 수 있다. 첨부만 있는 입력도 다룬다. 키보드와 모바일 터치로 모든 동작을 수행한다. 의존성: A01, A02.

- [x] **C02 빠른 저장과 중단 복구 연결**

  기존 저장 요청 복구를 작성기에 재사용한다. 원본 저장과 후속 분석의 완료를 구분하고, 중복 클릭·응답 유실·재시도에도 영감이 중복되지 않도록 한다. 업로드 중에는 실제 저장 완료를 정확히 표시한다.

  완료 기준: 한 번의 저장 의도가 서버에서 하나의 영감으로 확인된다. 실패 시 글과 첨부를 다시 작성하지 않아도 되고, 계정을 바꾸면 이전 사용자의 초안이 나타나지 않는다. 의존성: C01.

  완료 근거: 소유자별 IndexedDB 초안·첨부 묶음의 원자적 저장·저장 요청 복구를 연결했다. 실제 로컬 브라우저에서 업로드 실패, 새로고침, 성공 응답 유실 후 복구와 중복 없는 저장을 확인했다. C01의 작성기 구현은 연결됐으며, 모바일 실기기 검증은 A03과 함께 후속 확인으로 넘긴다. 상세 수치와 제한은 [실행 기록](../goals/personal-capture-foundation.md)을 따른다.

- [x] **C03 링크 저장과 미리보기**

  URL을 감지해 제목·사이트·이미지·원문 열기를 제공한다. 덧붙인 메모와 원문의 내용을 구분하고, 한 캡처에서 같은 링크가 중복 등록되지 않도록 한다.

  완료 기준: 링크만 저장해도 다시 찾을 수 있다. 메타데이터나 본문을 읽지 못해도 URL과 사용자 메모는 남으며 실패한 분석만 재시도한다. 인증이 필요한 페이지와 지원하지 않는 링크도 처리한다. 의존성: C02.

  완료 근거: 링크 상세에 제목·사이트·설명·권한 확인된 이미지·접을 수 있는 원문을 연결하고 사용자 메모와 구분했다. URL 표기 차이를 정규화해 중복 첨부를 막으며, 미리보기 실패 중에도 원본 링크를 유지한다. 첨부별 재시도와 전체 재처리는 같은 비용 제한을 사용한다. 실제 브라우저에서 링크만 저장·다시 열기·중복 방지·접근 제한 안내·한 첨부만 재시도하는 흐름을 확인했고, 390px에서 가로 넘침 없이 주요 클릭 영역 44px을 확인했다. 실기기·원격 배포는 별도이며 검증 수치는 [전체 실행 기록](../goals/personal-experience-delivery.md)에 남겼다.

- [x] **C04 사진 저장과 미리보기**

  선택·붙여넣기·드롭으로 사진을 첨부하고 미리보기, 업로드 진행, 개별 제거·재시도를 제공한다. 메모는 선택사항으로 둔다. 분석 결과는 사용자가 쓴 글과 구별한다.

  완료 기준: 사진만 저장한 뒤 상세에서 다시 볼 수 있다. 방향·대용량·지원하지 않는 형식·여러 첨부 중 일부 실패를 처리한다. 입력 한계를 넘기면 업로드 전에 설명하고 원본을 다시 고르게 만들지 않는다. 의존성: C02.

  완료 근거: 실제 파일 헤더로 사진 형식을 확인하고 원본 바이트·회전 정보를 유지한다. 지원하지 않는 파일·25MB 초과 파일·개수 초과 선택은 초안에 남겨 개별 제거할 수 있으며, 해결 전에는 저장을 막는다. 정상 사진과 이미 완료된 업로드는 유지한다. 파일별 업로드 상태·개별 재시도·브라우저 미리보기 불가 안내를 추가했다. 실제 브라우저에서 두 번째 업로드 실패→새로고침→개별 재시도→사진만 저장→원본 다시 보기와 EXIF 방향을 확인했다. 파일 선택·붙여넣기·드롭은 같은 검사 경로를 사용하며, 실기기는 합의대로 후속 검증이다. 측정값은 [전체 실행 기록](../goals/personal-experience-delivery.md)에 남겼다.

- [x] **C05 녹음 시작부터 저장까지의 화면**

  마이크 요청, 녹음 중 표시와 시간, 종료, 들어보기, 다시 녹음, 저장을 구현한다. 취소·완료·화면 종료 시 마이크를 해제한다. 길이 제한에 도달하면 녹음을 보존하고 다음 행동을 제시한다.

  완료 기준: 마이크 거절, 무음, 장치 없음, 중간 전화·앱 전환 시 결과가 명확하다. 로컬에만 있는 녹음과 서버에 저장된 녹음을 구분하며 재녹음 전에 기존 클립을 잃지 않는다. 의존성: C01, A03. 서버 연결은 C06과 함께 검증한다.

  완료 근거: 기존 녹음을 유지하는 재녹음·취소·새 클립 선택을 구현했고, 두 클립을 소유자별 초안에 보관해 새로고침 후 복구했다. 선택 전 저장 차단과 선택한 녹음 하나만 저장되는 것을 실제 브라우저/격리 DB로 확인했다. 장치 없음·사용 중·권한 거절·페이지 이탈·장치 연결 종료·길이 제한을 대상 테스트로 검증하며, 무음 안내는 C06 전사 결과와 연결한다. 실제 전화·화면 잠금 등 실기기 검증은 합의대로 후속이다.

- [x] **C06 오디오 업로드와 비동기 전사**

  오디오 첨부·길이·실제 MIME 검증과 필요한 마이그레이션을 추가한다. 원본 업로드 뒤 전사 작업을 큐에 넣고, 실패 재시도·비용 제한·동일 오디오 재사용을 처리한다. 전사문을 교정할 수 있게 하고 교정본을 재전사로 덮어쓰지 않는다.

  완료 기준: 전사 실패 중에도 원본 재생이 가능하다. 삭제·교정·계정 전환 후 늦게 도착한 전사가 이전 내용을 되살리지 않는다. 원본·전사·교정본이 삭제와 내보내기 정책에 함께 포함된다. 의존성: A01, A03, C02.

  완료 근거: 원본 업로드 후 전사 작업·형식/길이/용량 검사·완료된 전사 재사용·교정본 별도 보존·명시적 재시도와 비용 제한을 연결했다. 교정본은 분석·검색에서 우선 사용하고 오래된 인용과 벡터를 무효화한다. 실제 DB의 충돌·삭제·권한·내보내기 검사와 브라우저의 두 탭 충돌·교정 저장·원문 복원·실패 중 원본 재생을 확인했다. 합성 음성/무음 2건은 실제 작업 큐와 모델을 거쳐 통과했다. 실기기 검증은 합의대로 후속이며, dev 배포는 Q03에서 진행한다. 자세한 수치와 제한은 [전체 실행 기록](../goals/personal-experience-delivery.md)을 따른다.

- [ ] **C07 저장 후 이어지는 reflection**

  기존 `ReflectionFlow`를 재사용해 원본 저장 후 질문을 연다. 사용자가 쓴 글, 선택한 사진·링크의 확인 가능한 내용, 준비된 전사를 질문에 반영한다. 전사 대기 중에는 답을 지어내지 않고 메모를 받거나 준비 후 이어가게 한다. 답변마다 저장하고 다음 질문은 직전 답을 반영한다.

  완료 기준: 한 번 답하고 종료해도 완료된 경험이며, 다시 열면 저장된 답과 미완성 초안이 이어진다. 질문 실패·재시도로 답이 유실되거나 중복되지 않는다. 의존성: C02. 입력별 연결은 C03, C04, C06이 준비되는 대로 진행한다.

- [ ] **C08 저장한 영감의 공통 카드와 상세**

  사진, 링크 미리보기, 녹음 재생기·전사문, 사용자 메모, reflection 유무를 입력에 맞게 보여준다. 검색·리뷰·상세가 같은 원본과 같은 처리 상태를 표시하도록 한다. 전사와 reflection을 포함한 검색 범위는 A01 계약에 따라 확인한다.

  완료 기준: 네 입력 모두 다시 열고 원본을 확인하며 reflection을 이어갈 수 있다. 처리 실패가 빈 카드나 임시 문자열로 보이지 않는다. 원본 링크와 기존 딥링크가 유지된다. 의존성: C03–C07.

## R 영감 리뷰와 나의 생각

- [ ] **R01 홈의 Top of mind 가독성과 변화 표시**

  현재 생각을 홈에서 읽을 수 있는 크기로 보여준다. 근거가 된 영감, 최근 달라진 부분, 리뷰 시작을 가까이에 둔다. 작업 중에는 마지막으로 완료된 읽기를 유지하고, 새 결과가 준비되면 확인할 수 있게 한다.

  완료 기준: 처음 들어온 사용자도 현재 내용과 다음 행동을 구분한다. 데이터 없음·준비 중·변화 없음·실패를 정확히 처리하고, 과거 읽기와 현재 읽기를 혼동하지 않는다. 의존성: A02, 기존 Top of mind 기반.

- [ ] **R02 Principles 목록과 상세 정리**

  원칙마다 충분한 글자 크기와 여백을 주고 순서 조정·문구 수정·현재 동의 여부·근거를 일관된 위치에 둔다. 상세에서 공유와 아바타 대화로 연결한다. 기존 근거 부족·이견·사용자 수정 보존 규칙을 이어받는다.

  완료 기준: 원칙이 없는 사용자도 기대할 수 있는 흐름을 이해한다. 사용자 수정 문구가 생성으로 바뀌지 않고, 근거가 부족한 원칙을 확정된 사실처럼 보여주지 않는다. 의존성: A02, 기존 Principles 기반.

- [ ] **R03 리뷰 대상 선정과 세션 생성**

  아직 돌아보지 않은 최근 영감을 우선해 기본 5개 이내를 제안한다. 사용자가 직접 선택한 영감으로도 시작할 수 있게 한다. 시간 범위와 선정 이유는 간단히 설명하고, 준비되지 않은 녹음도 원본을 열 수 있게 한다.

  완료 기준: 영감이 0개·1개·많을 때 모두 자연스럽게 시작한다. 세션 중 새 영감이 들어와도 순서가 갑자기 바뀌지 않고, 삭제되거나 접근할 수 없어진 항목은 제거된다. 의존성: A01, C08.

- [ ] **R04 스와이프와 버튼으로 훑기**

  카드마다 ‘마음에 남아요’와 ‘이번엔 넘기기’를 제공한다. 스와이프와 버튼의 의미를 같게 하고, 직전 선택을 되돌리며 원하는 카드는 자세히 열 수 있게 한다. 진행 수는 세션 안에서만 표시한다.

  완료 기준: 넘기기로 원본이 삭제되거나 사용자의 반대 의견이 기록되지 않는다. 선택을 바꾸면 저장된 결과도 한 번만 갱신된다. 데스크톱 키보드와 모바일에서 동일하게 사용할 수 있다. 의존성: R03.

- [ ] **R05 여러 영감을 연결하는 짧은 대화**

  선택한 영감 사이의 연결을 하나 제안하고 질문을 한 번에 하나씩 한다. 사용자의 답에 따라 다음 질문을 바꾸며, 연결에 동의하지 않으면 그 답을 받아들인다. 공통점이 부족하면 한 영감부터 생각할 수 있게 한다.

  완료 기준: 질문에서 어떤 영감을 참고했는지 열어볼 수 있다. 하나에 대한 답은 해당 영감에 연결하고, 여러 영감에 걸친 답은 세션의 한 답변으로 저장해 같은 답을 여러 독립 근거로 복제하지 않는다. 의존성: C07, R03, A01.

- [ ] **R06 리뷰 완료와 다음 읽기 연결**

  새롭게 남긴 생각, Top of mind의 실제 변화, 관련된 기존 Principle을 간단히 보여준다. 변화가 없거나 원칙을 만들 근거가 부족한 경우도 정상적인 결과로 처리한다. 리뷰 저장과 읽기 생성의 완료 시점을 분리한다.

  완료 기준: 리뷰를 마쳤다는 이유만으로 새 원칙이 생기지 않는다. 새 결과를 눌렀을 때 해당 작업에서 실제 완성된 읽기가 열리고, 생성 실패는 저장된 답변에 영향을 주지 않는다. 의존성: R04, R05, R08.

- [ ] **R07 리뷰 중단과 재개**

  세션의 순서, 선택, 저장된 답, 현재 위치를 보존한다. 닫기·새로고침·Back·다른 기기에서 돌아오기를 처리한다. 미완성 로컬 초안은 저장된 답변과 구분하고 같은 계정·프로필에만 연결한다.

  완료 기준: 같은 질문에 답을 두 번 저장하지 않고 이어갈 수 있다. 중간에 원본이 수정되면 현재 원본을 기준으로 다시 확인하며 오래된 요약을 최신처럼 재사용하지 않는다. 의존성: R04, R05.

- [ ] **R08 리뷰가 생성에 미치는 영향 검증**

  선택은 리뷰 대상 선정에 사용하고, 사용자 답변은 내용과 출처를 가진 근거로 연결한다. 스와이프 횟수를 동의·확신·독립 경험의 수로 바꾸지 않는다. 최근 관심과 오래 유지되는 선택 기준을 구분하는 평가 사례를 추가한다.

  완료 기준: 같은 녹음·전사·reflection의 중복, 인용했지만 동의하지 않는 글, 잠깐의 관심, 원칙과 다른 새 경험, AI 제안만 있는 사례를 평가한다. 생성 기준을 바꿀 필요가 있으면 비교 결과를 먼저 기록하며, 사용자 수정과 반대 의견이 보존된다. 의존성: A01, R04, R05.

## S Principles 공유 아티팩트

- [ ] **S01 원칙 한 장의 편집 화면**

  Principle 선택, 공유용 문구 수정, 이름 표시 여부와 간단한 디자인 선택, 실시간 미리보기를 제공한다. 공유용 문구는 원칙 원본과 별도로 다룬다. 기본 카드에는 선택한 문장만 담는다.

  완료 기준: 공유 문구를 고쳐도 원래 Principle과 순서가 바뀌지 않는다. 미리보기에 없는 개인 메모·근거·reflection이 결과물에 포함되지 않는다. 의존성: A01, R02.

- [ ] **S02 이미지 렌더링과 다운로드**

  정사각형과 세로형 카드, 한국어·영어 문구, 줄바꿈과 긴 문장을 지원한다. 초기에는 디자인 두 개 이내로 제한하고, 미리보기와 같은 이미지 파일을 만든다.

  완료 기준: 글자가 잘리지 않으며 작은 화면에서도 읽을 수 있다. 폰트 준비 후 렌더링하고, 폰트 실패 시에도 대체 글꼴로 전체 문장이 보인다. 다운로드한 파일의 내용·크기가 미리보기와 일치한다. 의존성: S01.

- [ ] **S03 공유 동작과 완료 처리**

  지원되는 환경에서는 OS 공유창을 열고, 그 외에는 이미지 저장을 제공한다. 생성 실패·공유 취소·다시 시도를 처리한다. 공유할 내용은 최종 미리보기에서 확인한다.

  완료 기준: 공유창을 열었다는 이유만으로 외부 앱에 게시됐다고 표시하지 않는다. 취소해도 편집 내용이 남고, 반복 시도로 영감이나 Principle이 새로 생성되지 않는다. 개인 아카이브의 공개 설정도 자동 변경되지 않는다. 의존성: S02, A03의 플랫폼 결정.

- [ ] **S04 기준 모음과 생각의 변화 카드**

  사용자가 고른 원칙 최대 세 개의 모음과 실제 과거·현재 문구를 비교하는 카드를 만든다. 필요한 과거 문구 보존 기능이 없는 경우, 앞으로의 변경부터 기록하는 계약을 먼저 구현한다. 사용자에게 없는 과거의 생각을 AI로 만들어 채우지 않는다.

  완료 기준: 이전·현재 문구와 날짜가 실제 저장 기록에 연결된다. 기록이 없으면 한 장 카드나 모음을 사용할 수 있다. 과거 문구의 수정·삭제·내보내기 범위도 정해진다. 의존성: S03, A01, R01, R02.

## V Principles 아바타 대화

- [ ] **V01 아바타 대화 화면**

  기존 캐릭터를 활용하고, reflection·리뷰에서 익숙해진 존재와 대화를 이어가도록 한다. 대화 시작 예시, 메시지 목록, 입력, 응답 대기, 중지·재시도를 제공한다. Principle 상세에서도 해당 문장을 주제로 시작한다.

  완료 기준: 모바일 키보드가 입력창을 가리지 않고, 긴 대화를 읽다가 새 메시지로 강제 이동하지 않는다. 처음부터 대화 기록과 현재 대화의 위치를 구분할 수 있다. 의존성: A02, R02.

- [ ] **V02 대화 저장과 참고할 기억 구성**

  계정·프로필별 대화와 메시지를 저장한다. 현재 Principles, 우선순위·이견·근거 상태, Top of mind와 질문에 관련된 영감을 필요한 만큼 검색한다. 대화 기록의 삭제·내보내기와 비용·입력 길이 제한도 정의한다.

  완료 기준: 다른 프로필의 기억이 섞이지 않는다. 삭제된 자료와 철회된 근거는 다음 응답의 사실 근거로 사용하지 않고, 사용자가 과거 대화를 다시 열 수 있다. 의존성: A01, R02.

- [ ] **V03 근거를 가진 답변과 후속 질문**

  내 생각 이해하기, 선택 고민하기, 변화 돌아보기의 세 상황을 지원한다. 실제 저장된 기준과 현재 상황의 조건을 연결하고, 서로 충돌하는 기준도 질문에 활용한다. 답변에서 참고한 Principle이나 영감을 짧게 열어볼 수 있게 한다.

  완료 기준: 사용자가 말하지 않은 경험을 지어내지 않는다. 근거가 적으면 필요한 맥락을 묻고, 응답이 끊겨도 사용자 메시지는 남는다. 인용한 자료는 실제로 열리며 중지·재시도는 중복 메시지를 만들지 않는다. 의존성: V01, V02.

- [ ] **V04 대화에서 생각 남기기와 정정하기**

  선택한 문장을 확인·편집한 뒤 영감으로 저장한다. 사용자의 말, 아바타 제안, 사용자가 채택해 다시 쓴 말을 구분한다. ‘내 생각은 달라’에서 대화 정정이나 명시적인 Principle 수정으로 연결한다.

  완료 기준: 대화의 모든 AI 응답이 자동으로 새 개인 근거가 되지 않는다. 한 번의 저장은 하나의 영감으로 남고, 원칙 수정은 확인한 문구와 버전에만 반영되며 사용자 문구가 보존된다. 의존성: V03, C02, R02.

- [ ] **V05 아바타 답변의 제품 품질 평가**

  원칙 없음, 서로 충돌하는 원칙, 사용자가 수정한 원칙, 오래된 관심, 달라진 생각, 근거 철회, 선택에 필요한 정보 부족의 사례로 평가한다. 사용자가 직접 정정한 뒤 다음 답이 달라지는지도 확인한다.

  완료 기준: 평가 사례별로 답변 근거, 필요한 질문, 사용자가 얻는 도움을 기록한다. 잘못된 기억 인용과 다른 프로필 내용 노출은 출시를 막는다. 단순히 항상 동의하는 답변은 개선 대상으로 남긴다. 의존성: V03, R08.

## Q 버그와 출시 검증

- [ ] **Q01 캡처와 녹음의 실패 경로 검증**

  네 가지 단독 입력과 혼합 입력을 실제 앱에서 저장·다시 열기·reflection까지 확인한다. 네트워크 단절, 응답 유실, 첨부 일부 실패, 마이크 거절·중단, 전사 실패·교정, 새로고침, 계정 전환을 포함한다.

  완료 기준: 원본·사용자 답변 유실, 중복 생성, 저장 상태의 잘못된 안내가 없는 검증 결과를 남긴다. 발견한 버그는 해당 C 태스크의 완료 조건으로 되돌려 고친다. 의존성: C08.

- [ ] **Q02 리뷰와 공유의 연결 검증**

  캡처 → 다시 찾기 → 리뷰 선택 변경 → 중단·재개 → 실제 읽기 확인 → 원칙 카드 저장·공유를 데스크톱과 모바일에서 검증한다. 터치 영역, 글자 크기, 키보드, 스크롤, 주소·Back 동작과 빈 상태를 포함한다.

  완료 기준: 콘텐츠 유실·허위 완료·공유 범위 오류가 없고, 미리보기와 이미지가 일치한다. R06·R07 완료 시 리뷰를 먼저 검증하고 S03 완료 시 공유를 추가 검증한다. 해당 기능의 출시를 서로 불필요하게 묶지 않는다. 의존성: R06, R07; 공유 검증은 S03.

- [ ] **Q03 단계별 배포와 사용 결과 확인**

  각 묶음에서 필요한 타입 검사·대상 테스트·빌드와 스키마 검증을 실행한다. PR마다 결과와 남은 문제를 적고, dev 반영 후 같은 사용자 흐름을 확인한다. 저장 실패율, 리뷰 시작·완료·재방문, 카드 생성·내보내기, 대화에서 생각 남기기를 내용 본문 없이 측정한다.

  완료 기준: 단계별 배포·되돌리기 방법과 실제 dev 검증 결과가 있다. 첫 세션과 다음 세션의 관찰을 통해 다음 작업 우선순위를 정한다. 통과하지 못한 기기나 입력은 지원 완료로 표시하지 않는다. 의존성: 각 출시 묶음; 아바타 출시는 V04, V05.

## 첫 구현 묶음

가장 먼저 A01·A02와 C01·C02를 진행해 텍스트·사진·링크·녹음이 들어갈 공통 작성기와 저장 의미를 고정한다. 동시에 A03에서 녹음의 실제 기기 제약을 확인한다. 다음에는 C03·C04와 C05·C06을 각각 구현해 연결한다. 기존 reflection은 C07에서 재사용한다.

각 체크박스는 구현과 완료 기준 검증을 함께 만족한 뒤 체크한다. 큰 태스크는 하위 PR로 나눌 수 있지만, 화면만 만들었거나 API만 추가한 상태로 사용자 흐름이 완성됐다고 처리하지 않는다. 기한과 담당자는 실제 작업량을 확인한 뒤 붙인다.
