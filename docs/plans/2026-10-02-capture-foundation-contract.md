# WAKA 캡처와 개인 경험 데이터 계약

상태: A01 구현 계약. 2026년 10월 2일 합의한 개인 경험의 첫 작업 묶음에 적용한다. 리뷰·대화·공유 관련 저장 단위는 이후 기능의 계약이며 아직 구현된 API가 아니다.

## 한 영감의 구성

영감은 한 번의 저장 의도다. 사람이 쓴 텍스트와 링크·사진·녹음 첨부를 함께 가질 수 있다. 텍스트가 없어도 첨부가 있으면 유효하다. 사진이나 녹음 대신 가짜 본문을 넣지 않는다. 목록의 이름은 실제 메모, 링크 제목, 첨부 종류·파일명에서 표현용으로 만든다.

원본 텍스트와 원본 파일은 생성 작업이 다시 쓰지 않는다. 파일의 소유 프로필과 부모 영감의 소유 프로필은 일치한다. 사람의 기억, 에이전트의 기억, 그룹의 자료에 대한 기존 서버 권한은 그대로 적용한다.

| 자료 | 저장 단위 | 변경하는 행동 | 생성에서의 의미 |
| --- | --- | --- | --- |
| 사람이 쓴 메모 | inspiration의 원문 | 작성·명시적인 편집 | 사람의 말 |
| 링크·사진·녹음 | inspiration에 속한 attachment | 추가·교체·명시적인 삭제 | 원본 자료. 저장했다는 사실만으로 내용에 동의했다고 판단하지 않음 |
| 이미지·링크 분석 | attachment의 기계 분석 | 원본 변경에 따른 재분석 | 원문의 설명. 사람의 직접 발언과 구분 |
| 녹음 전사 | audio attachment에서 파생된 전사 | 원본에 맞춘 전사·재시도 | 원음에서 무엇을 읽었는지. 원음과 같은 근거 묶음 |
| 전사 교정 | 해당 전사에 대한 사용자 교정 | 사용자의 명시적인 편집 | 교정된 문구를 우선 사용하며 재전사가 덮어쓰지 않음 |
| 개별 reflection | inspiration에 속한 질문과 사용자 답 | 답변 저장·명시적인 철회 | 개인적인 해석. 원본 공개와 별개로 비공개 |
| 여러 영감에 대한 답 | review session의 한 사용자 응답과 참조 항목 | 세션 응답 저장·수정·삭제 | 같은 답을 각 영감에 복제하거나 독립 경험 여러 개로 계산하지 않음 |
| 아바타 대화 | profile 소유 conversation과 메시지 | 보내기·삭제·선택 저장 | AI 응답이 자동으로 개인의 새 신념 근거가 되지 않음 |
| 공유 이미지 | 선택한 문구와 옵션의 내보내기 결과 | 미리보기 확인 후 내보내기 | 원래 Principle의 문구·순위·공개 설정을 바꾸지 않음 |

전사는 첨부 분석의 한 종류이며 원본을 대체하지 않는다. 낮은 품질이나 무음이면 추측한 문구를 채우지 않고 재생·재시도를 제공한다. 교정과 원본 교체는 관련 자료의 revision을 바꾸므로 늦게 도착한 이전 분석은 반영하지 않는다. C06에서 전사 저장·교정·큐를 구현할 때 이 계약을 적용한다.

## 저장과 복구

작성 중인 텍스트와 파일은 계정·프로필에 귀속된 로컬 초안으로 보관한다. 파일 바이트는 IndexedDB에 두고, localStorage에 Base64로 넣지 않는다. 저장소가 막히거나 공간이 부족하면 보존을 약속하지 않고 초안을 화면에 유지한다.

파일을 업로드한 뒤 하나의 변경되지 않는 요청 ID로 영감과 첨부 목록을 저장한다. 서버는 영감·첨부 행·처리 요청을 함께 커밋한다. 파일 업로드만 끝난 상태는 영감 저장 완료가 아니다. 첨부 실패는 작성기의 해당 항목에 표시하고 이미 끝난 업로드와 사용자 글은 보존한다.

서버 응답이 유실되면 같은 요청 ID로 조회하고 재시도한다. 저장 여부가 불명확할 때 새로운 ID로 다시 저장하지 않는다. 성공 확인은 해당 의도와 일치하는 초안만 정리하며, 그 사이 작성한 새 글이나 다른 탭의 초안을 지우지 않는다. 프로필 전환 후 이전 응답으로 현재 화면을 바꾸지 않는다.

‘저장하기’는 원본의 영구 저장을 확인하고 종료한다. ‘생각 이어가기’도 원본 저장을 먼저 확인하고 해당 영감의 reflection을 연다. 분석 완료를 기다리느라 저장을 막지 않는다. 오디오 원본 저장과 전사 완료도 별도다.

## 리뷰 선택

리뷰 세션은 대상 영감 ID와 당시 revision, 순서, 선택, 저장된 답, 현재 위치를 가진다. 새 영감이 생겨도 진행 중인 순서에 끼워 넣지 않는다. 삭제·접근 철회된 항목은 세션에서도 열리지 않는다.

- ‘마음에 남아요’는 이번 세션에서 더 살펴볼 대상으로 선택한다.
- ‘이번엔 넘기기’는 이번 세션에서 넘어간다. 원문·근거·원칙의 부정이나 삭제를 의미하지 않는다.
- 직전 선택 변경은 같은 세션 항목을 갱신한다. 선택 횟수를 여러 동의로 세지 않는다.
- 실제 사용자 답변은 출처와 함께 의미를 해석한다. 선택만으로 Principle을 확정하지 않는다.

여러 영감에 걸친 답변은 한 응답으로 보관한다. 해당 응답의 분석에서 참조한 원본 계보를 유지해 원음·전사·reflection·세션 답변의 중복이 반복 경험처럼 계산되지 않도록 한다. 구체적인 분석 연결은 R05·R08의 구현과 평가 대상이다.

## 대화와 공유

아바타가 참고한 기억과 답변 인용은 해당 사용자에게 현재 허용되는 자료여야 한다. ‘이 생각 남기기’는 선택한 문구를 확인한 뒤 하나의 영감으로 저장한다. 사용자가 직접 쓴 말과 AI가 제안한 말의 출처를 유지한다. 대화의 제안을 자동으로 Principle 수정에 적용하지 않는다.

공유 문구는 내보내기를 위한 독립적인 초안이다. 원칙 원문을 수정하려면 원칙 편집을 별도로 수행한다. 기본 공유물에는 선택한 문장과 사용자가 허용한 표시 정보만 넣고, 원본 영감·reflection·녹음·전사를 자동으로 포함하지 않는다. 내보내기가 개인 아카이브를 공개하지 않는다.

## 구체적인 예

한 사용자가 전시 사진, 웹페이지 링크, ‘여백이 있어서 생각하기 편했다’라는 30초 녹음과 짧은 메모를 한 번 저장한다.

1. 사진·녹음 파일을 올린 뒤 한 요청 ID로 영감 1개와 첨부 3개를 함께 확정한다. 재시도로 영감이나 첨부가 늘어나지 않는다.
2. 링크·사진 분석과 녹음 전사는 파생 자료다. 녹음 전사가 실패해도 원본은 재생할 수 있다. 이 전체를 독립 영감 네 개로 세지 않는다.
3. 사용자가 reflection으로 ‘최근 일정을 너무 꽉 채운 것 같다’고 답하면 그 영감의 비공개 답변 하나를 저장한다.
4. 리뷰에서 ‘마음에 남아요’를 선택하면 이번 대화 대상으로 고른다. 여백을 항상 좋아한다는 확정 판단이 되지 않는다.
5. 다른 영감과 비교해 ‘일을 덜어내면 중요한 것을 잘 선택한다’고 답하면 세션의 한 응답으로 저장하고 관련 영감을 참조한다.
6. 아바타와의 대화에서 현재 선택을 살펴본다. 새 Principle 여부는 근거와 생성 기준에 따라 결정되고, 사용자가 고친 원칙 문구는 보존된다.
7. ‘중요한 선택을 위해 여백을 남긴다’라는 원칙을 공유할 때 카드용으로 문구를 줄여도 원칙 원문과 녹음 공개 범위는 바뀌지 않는다.

## 화면 상태와 이동 계약

| 화면 | 처음과 빈 상태 | 진행과 실패 | 돌아왔을 때 |
| --- | --- | --- | --- |
| 홈 | 실제 Top of mind와 Principles를 읽고 캡처·리뷰로 이동. 없으면 첫 캡처 진입 | 마지막으로 완료된 읽기를 유지하고 현재 작업 결과를 구분 | 선택한 읽기·섹션·날짜 복원 |
| 캡처 | 같은 작성기에 텍스트·링크·사진·녹음 추가 | 항목별 업로드, 저장 의도 확인, 실패 항목 재시도 | 소유한 미완료 글과 파일 복원 |
| 영감 상세 | 원본 종류에 맞는 미리보기·재생·reflection 표시 | 분석 실패와 원본 저장 여부 구분 | 원본과 열린 답변의 링크 복원 |
| 리뷰 | 대상이 있는 만큼 시작, 없으면 새 영감으로 이동 | 항목별 선택·질문·저장 상태. 원본 철회 반영 | 같은 세션 위치·선택·저장된 답으로 복원 |
| 원칙과 공유 | 실제 원칙 선택과 공유 초안 미리보기 | 이미지 생성 실패·공유 취소 시 편집 보존 | 공유 초안 복원, 원칙 원문은 별도 |
| 아바타 | 실제 기억에 기반한 시작 제안, 기억 부족 시 맥락 질문 | 사용자 메시지를 보존하고 응답 중지·재시도 | 소유한 대화와 읽던 위치로 복원 |

핵심 입력과 확인 동작은 최소 44px 터치 영역을 둔다. 모바일에서는 한 열로 재배치하고 키보드가 완료 동작을 가리지 않게 한다. 세로 스크롤은 열린 입력·리뷰 화면이 소유한다. Enter는 줄바꿈, Ctrl/Cmd+Enter는 저장이며 IME 조합 중에는 저장하지 않는다. Escape·닫기는 초안을 보존한다. 주소와 Back은 선택한 화면을 복원하되 본문·전사·검색어를 URL에 넣지 않는다.

A02의 구체적인 화면안은 별도 프로토타입에서 이 표의 상태를 확인한다. 이 계약 표만으로 A02의 시각·모바일 검증을 완료한 것으로 처리하지 않는다.
