WWAKA · Wow Moment Engine

Core idea

The wow is not the label. The wow is the connection.

When someone adds an inspiration, WAKA should look for a pattern that makes the user think: “I didn’t realize I kept circling this.”

Example reveal

“This unexpectedly rhymes with your older notes on ritual spaces.”

NewA messy note, link, or image.
FoundRelated, distant, or opposing prior ideas.
WowA short explanation the user can believe.

Constraint

Run discovery every time. Do not run the LLM over everything.

Avoid

Full archive LLM scan

  • Expensive as the archive grows
  • Slow after every save
  • Hard to make deterministic
  • Tempts the model to invent connections
Use instead

Embedding search → heuristic scoring → small LLM judgment

  • One embedding for the new inspiration
  • Cheap vector search for candidates
  • Scores decide which kind may apply
  • LLM only judges the strongest small set

Detection happens on every insert. A visible wow moment appears only when the evidence is strong.

Simple pipeline

Five steps from new inspiration to possible wow moment.

Save

Persist the inspiration immediately so the product feels instant.

Embed

Turn the new inspiration into a vector: coordinates in meaning-space.

Retrieve

Find nearby, distant-salient, and centroid candidates from the user's archive.

Score

Calculate motif, bridge, tension, outlier, and surprise scores.

Judge

Ask the LLM only about top candidates: “Is this defensible or forced?”

Embedding finds candidates. Heuristics rank them. The LLM confirms and phrases the moment.

MVP wow kinds

Start with five understandable moments.

Recurring

Motif

You keep returning to the same idea.

High similarity + several related items + time spread.
Connected

Bridge

This connects two or more known themes.

Related items come from different clusters.
Surprise

Surprise bridge

Seemingly unrelated things share a deeper structure.

Mid-distance + high salience + LLM-confirmed analogy.

The surprise element

Tension and outlier make WAKA feel less like search.

Friction

Tension

Two ideas are related, but they pull in opposite directions.

  • Same underlying topic
  • Opposing values or assumptions
  • Requires LLM confirmation
Example: “I want calming minimal tools” vs “dense dashboards make me feel powerful.”
Frontier

Outlier

A rich new item sits outside the user's usual archive.

  • Low similarity to nearest items
  • Low similarity to theme centroids
  • Enough substance to be worth noticing
Careful copy: “This may be the start of a new thread.”

Heuristic scoring

embedding = coordinates heuristics = measurements over those coordinates kind = interpretation of the pattern LLM = final semantic judge

The embedding does not say “this is tension.” It lets us measure similarity, distance, density, diversity, and time spread.

Decision

Readable formulas

The math is intentionally simple.

Obvious resonance
motif = similarity + related count + time spread + richness bridge = cluster diversity + multi-cluster similarity + richness tension = topic relatedness + contrast hints + question/stance language
Surprise
outlier = archive distance + richness surprise bridge = mid-distance sweet spot + candidate salience + different cluster + time distance

For surprise bridge, do not look for maximum distance. Look for the sweet spot: not obvious, not random.

Trust gates

Protect the magic by rejecting weak moments.

Cheap gates

  • Archive has enough history
  • Input has enough richness
  • Candidate score clears threshold
  • Only top candidate kinds proceed

LLM gates

  • Reject vague or forced links
  • Require a defensible explanation
  • Tension needs opposing values
  • Surprise needs shared structure

Saved wow

  • kind
  • score
  • title
  • short explanation
  • related inspiration IDs
  • reflection question

The product promise: WAKA searches every time, but only speaks when the connection is worth trusting.
