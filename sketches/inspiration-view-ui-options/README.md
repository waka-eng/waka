# Inspiration view UI options

Style-preserving mockups for improving the opened sticky-note inspiration/evidence view without changing the overall WAKA UI too much.

- `option-a-evidence-trail`: safest/minimal change; vertical evidence trail.
- `option-b-receipt-stack`: tactile paper slips; more playful but still aligned.
- `option-c-marginalia`: smartest/most explanatory; source excerpts with WAKA annotations.
